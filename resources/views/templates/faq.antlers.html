{{ /partial:components/accordion/content }} {{ /partial:components/accordion/item }} {{ partial:components/accordion/item id="kann-ich-die-wohnungen-bereits-besichtigen" }} {{ partial:components/accordion/button title="Kann ich die Wohnungen bereits besichtigen?" }} {{ partial:components/accordion/content }}

Aktuell sind keine Besichtigungen möglich, da die Wohnungen ab Plan vermietet werden.

{{ /partial:components/accordion/content }} {{ /partial:components/accordion/item }} {{ partial:components/accordion/item id="wie-kann-ich-mich-bewerben" }} {{ partial:components/accordion/button title="Wie kann ich mich für eine Wohnung bewerben?" }} {{ partial:components/accordion/content }}

Wählen Sie unter dem Menüpunkt Angebot Ihr gewünschtes Objekt aus, klicken Sie auf Anmeldeformular und füllen Sie das Formular digital aus. Die Anleitung zum digitalen Bewerbungsprozess finden Sie im Dokument Anleitung digitaler Bewerbungsprozess.

{{ /partial:components/accordion/content }} {{ /partial:components/accordion/item }} {{ partial:components/accordion/item id="kann-ich-eine-wohnung-provisorisch-reservieren" }} {{ partial:components/accordion/button title="Kann ich eine Wohnung provisorisch reservieren?" }} {{ partial:components/accordion/content }}

Nein, provisorische Reservationen sind nicht möglich. Sobald wir Ihre Anmeldung erfolgreich geprüft haben, erhalten Sie eine Zusage per E-Mail. Anschliessend senden wir Ihnen den Mietvertrag zur Unterzeichnung zu.

{{ /partial:components/accordion/content }} {{ /partial:components/accordion/item }} {{ partial:components/accordion/item id="wie-lange-ist-die-mindestmietdauer" }} {{ partial:components/accordion/button title="Wie lange ist die Mindestmietdauer und welche Kündigungsfristen gelten?" }} {{ partial:components/accordion/content }}

Der Mietvertrag läuft mindestens ein Jahr. Das Mietverhältnis kann mit einer Frist von drei Monaten auf jedes Monatsende, ausgenommen Dezember, gekündigt werden.

{{ /partial:components/accordion/content }} {{ /partial:components/accordion/item }} {{ partial:components/accordion/item id="wie-hoch-ist-die-mietkaution" }} {{ partial:components/accordion/button title="Wie hoch ist die Mietkaution?" }} {{ partial:components/accordion/content }}

Die Mietkaution beträgt drei Bruttomonatsmieten und wird auf einem Mietkautionssparkonto hinterlegt. Eine Versicherungsleistung ist ebenfalls möglich.

{{ /partial:components/accordion/content }} {{ /partial:components/accordion/item }} {{ partial:components/accordion/item id="sind-haustiere-erlaubt" }} {{ partial:components/accordion/button title="Sind Haustiere erlaubt?" }} {{ partial:components/accordion/content }}

Hunde und Katzen sind nicht erlaubt. Kleine Haustiere, die in der Wohnung bleiben, sind grundsätzlich gestattet.

{{ /partial:components/accordion/content }} {{ /partial:components/accordion/item }} {{ partial:components/accordion/item id="gibt-es-eigene-waschmaschinen" }} {{ partial:components/accordion/button title="Gibt es eigene Waschmaschinen in den Wohnungen oder einen gemeinschaftlichen Waschraum?" }} {{ partial:components/accordion/content }}

Jede Wohnung verfügt über eine eigene Waschmaschine und einen eigenen Tumbler.

{{ /partial:components/accordion/content }} {{ /partial:components/accordion/item }} {{ partial:components/accordion/item id="wie-ist-der-ausbau" }} {{ partial:components/accordion/button title="Wie ist der Ausbau der Küche und der Bäder?" }} {{ partial:components/accordion/content }}

Alle Informationen dazu finden Sie im Ausbaubeschrieb.

{{ /partial:components/accordion/content }} {{ /partial:components/accordion/item }} {{ partial:components/accordion/item id="gibt-es-einen-balkon" }} {{ partial:components/accordion/button title="Gibt es einen Balkon, Sitzplatz oder eine Terrasse?" }} {{ partial:components/accordion/content }}

Jede Wohnung verfügt über einen grosszügigen Balkon, Sitzplatz oder eine Terrasse mit Flächen zwischen 15.1 und 48.4 m².

{{ /partial:components/accordion/content }} {{ /partial:components/accordion/item }} {{ partial:components/accordion/item id="sind-einstellplaetze-verfuegbar" }} {{ partial:components/accordion/button title="Sind Einstellplätze verfügbar und wie hoch ist der Mietzins?" }} {{ partial:components/accordion/content }}

Es stehen Einstellplätze zur Verfügung. Aktuell darf pro Wohneinheit ein Parkplatz angemietet werden. Sollten zusätzliche Plätze verfügbar sein, informieren wir die Mieterinnen und Mieter, die ein entsprechendes Bedürfnis gemeldet haben. Die Mietzinse finden Sie unter Angebot.

{{ /partial:components/accordion/content }} {{ /partial:components/accordion/item }} {{ partial:components/accordion/item id="sind-e-einstellplaetze-vorhanden" }} {{ partial:components/accordion/button title="Sind E-Einstellplätze vorhanden und kann ein Platz später nachgerüstet werden? Wie hoch ist der Mietzins?" }} {{ partial:components/accordion/content }}

Es besteht die Möglichkeit, einen E-Einstellplatz zu mieten. Bitte geben Sie dies bei der Anmeldung an. Sie werden dann entsprechend berücksichtigt. Auch eine spätere Nachrüstung nach dem Einzug ist möglich. Die Mietzinse entsprechen jenen der normalen Einstellplätze und sind unter Angebot aufgeführt.

{{ /partial:components/accordion/content }} {{ /partial:components/accordion/item }} {{ partial:components/accordion/item id="wie-funktioniert-die-e-ladeinfrastruktur" }} {{ partial:components/accordion/button title="Wie funktioniert die E-Ladeinfrastruktur?" }} {{ partial:components/accordion/content }}

Das Kabelband für die Ladeinfrastruktur ist bereits vorhanden. Die Anschaffung der Ladestation sowie die Anmeldung beim Betreiber erfolgen nicht über die Bewirtschaftung. Wir unterstützen Sie jedoch gerne dabei.

Ja, es stehen Besucherparkplätze im Aussenbereich zur Verfügung.

Ja, in der Umgebung der Liegenschaft befindet sich ein Spielplatz.
